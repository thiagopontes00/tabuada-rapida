# Registros de decisão de arquitetura (ADRs)

Cada ADR registra **uma decisão importante**: o contexto, o que foi decidido, as alternativas e as consequências. O formato é o de Michael Nygard, que é o mais usado no mercado.

**Regras:**
- Um ADR aceito não é apagado. Se a decisão mudar, crie um ADR novo e marque o antigo como "Substituído por ADR-XXXX".
- Numeração sequencial, com nome curto em kebab-case.
- Para criar um novo, copie o [template](0000-template.md).
